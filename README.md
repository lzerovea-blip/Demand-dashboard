# 解决方案需求管理

面向运动健康、穿戴方案团队的离线需求汇总工具。它用于结构化录入需求、按领域合并路标卡片、按半年统计工作量，并按确认后的内置模板输出路标材料。

## 直接启动（macOS）

在项目根目录双击 `启动解决方案需求管理.command`，或直接打开 `release/解决方案需求管理.app`。

不要在浏览器里打开 `src/renderer/index.html`：它是开发源码入口，离开 Electron 桌面环境后无法访问本地数据库和文件能力。

## Windows 版本

GitHub Release 仅提供 64 位 Windows 便携版：

- `Solution-Requirements-Manager-Portable-<版本号>-x64.exe`：便携版，无需安装即可运行。

便携版包含离线数据库、PPT 共创模板和工作区数据包能力，运行时不依赖网络。后续 GitHub Release 只上传 Windows 便携版，不上传安装版、Mac 或 iOS 产物。当前构建未使用商业代码签名证书，Windows 首次运行时可能显示“未知发布者”或 SmartScreen 提示；应在可信来源下载并核对发布文件。

## 当前能力

- 单机 SQLite 数据库，运行时不访问网络。
- 侧栏和内置使用说明显示应用版本、发版时间及制作者。
- 十四类来源：运动/健康各含基础、进阶、高阶，以及行业、全场景、health平台、AI运动、AI健康、AI综合、NMPA送检、CE送检；历史 AI/ai 自动迁移为 AI综合，历史医疗送检自动迁移为 NMPA送检。
- 领域字典分为 L0 与 L1，一个 L0 可关联多个 L1；L0、L1 和产品标签支持双击改名，L1 可按所属 L0 筛选。新建需求先选 L0，再从其子级中选择 L1，路标卡片只显示并按 L1 合并。
- 三类分类：体验优化、平台演进、产品专属；体验优化不匹配产品，平台演进可选一个产品，产品专属必须匹配一个产品。
- 单个上线年月；设备、App、云侧三端工作量均可留空或填写 0，支持整数或小数并自动合计。
- 三端工作量合计为 0 的需求会在需求池标记为“工作量待评估”，便于后续集中补充。
- 每条需求可补充描述和最多 5 张本地图片，图片随离线数据备份保留。
- 需求池支持立即复制完整需求，副本会重新生成需求和图片 ID，并自动递增“副本（1）”序号。
- 人员字典支持姓名、唯一工号、唯一 Microsoft 365 企业账号、单岗位角色和多个负责领域 L1；列表可按角色、负责领域 L0/L1 联动筛选，录入的 L0 筛选独立，切换后保留跨 L0 的已选 L1。
- 需求池仅按关键词、领域 L0/L1、上线版本、规划、产品经理和 SE 组合筛选；不提供来源、分类或匹配产品筛选。三个责任人均支持“未配置”；只显示姓名，版本按半年由新到旧排序。
- v0.8.9：需求及字典领域变更同步分层分级（包括历史基线），启动时幂等修复旧关联缓存，保留支持状态和历史记录；标签删除按实际引用检查并提示处理位置。保留 v0.8.8 PPT 自动续页。
- 需求池展示需求标题、领域 L1、来源、上线月份及自动计算的 HMOS 版本、匹配产品、规划、产品经理、SE 和工作量，并在当前页面宽度内完整排布、不产生横向滚动；领域 L0、适用范围、分类仍保留在需求数据和编辑器中，但不占用列表列宽。
- 需求池标题随列宽自然换行，完整显示且不限制行数；连续英文等超长内容也可断行，避免挤压其他字段或产生横向滚动。
- 按“领域 L1 + 来源 + 上线年月”自动合并卡片，分类不同、L0 不同仍可合并。
- 按时间汇总设备/App/云侧工作量，并用圆饼图呈现三端、七类路标来源、体验优化/平台演进/产品专属占比。
- 汇总分析、路标和导出中心分别保留自己的半年区间，切换页面不会相互覆盖时间选择。
- 固定展示三端投入分组柱状图；可切换设备、App 或云侧，查看所选端中体验优化、平台演进、产品专属三类并列占比柱。
- 运动、健康、行业、全场景、health平台、AI、医疗送检七张路标；页面内“全屏查看”进入七 Tab 沉浸模式，系统窗口全屏只放大普通页面，按 Esc 退出沉浸模式。全屏固定当前路标标题、半年与 HMOS 版本、月份表头，切换 Tab 后从顶部开始浏览。运动与健康使用高阶/进阶/基础三级泳道，AI 路标使用 AI运动/AI健康/AI综合三级泳道，医疗送检路标使用 NMPA送检/CE送检双泳道，其余路标使用单一需求泳道；每张路标独立判断月份占用，空月份固定压缩为 56px。
- 领域卡片标题固定使用领域 L1 标签，不支持手工标题或摘要；点击后默认展开全部需求、产品、总工作量、需求描述和图片，不在详情中重复显示设备/App/云侧拆分；点击图片可在全窗口查看层中按原始比例完整显示，并通过底部缩略图切换同一需求的其他图片。
- 普通路标中，同一泳道、同一月份的多张卡片可直接上下拖拽排序；全屏预览保持只读，排序会同步到 PPT 和数据交接文件。
- 路标轴使用长条卡片，整段文案每行最多 20 字、最多两行，最多取三条需求标题并保留产品标识，完整内容在详情页查看。
- 路标卡片匹配产品时继续显示“涉及产品”；包含体验优化需求时在卡片右侧显示体验优化图标。
- 独立“分层分级”模块按 L0、L1、需求三级结构离线维护需求与 9 个华为产品系列的支持矩阵；可勾选需要展示的系列，并查看状态变更记录。
- 系列支持状态简化为支持、不支持、未判断；单元格可直接切换，均未选择时即为未判断，保存后自动记录变更。
- 新建需求会自动建立分层分级关联并将九个系列初始化为未判断；普通需求编辑、复制和删除会同步对应矩阵行。历史基线需求被删除时只解除关联，仍可重新生成。
- 156 条历史需求按中国大陆首次公开可用证据分布在 2014—2025 年；明确月份直接记录，只有半年证据时 H1 暂存 4 月、H2 暂存 9 月，只有年份证据时落入最可信半年。所有占位月份均显示“月份待核验”或“半年及月份待核验”，不会冒充真实首发月。
- 本地领域 L0 / L1 / 产品 / 人员字典，以及包含需求、描述、原图、卡片编辑、人员责任矩阵、PPT 白名单和完整分层分级数据的 `.roadmap` 数据交接包。
- 支持导出/回导 v6 单 Sheet 协作 Excel，仅在“需求清单”A–N 展示可编辑业务字段；需求 ID、基线与下拉字典保存在 XLSX 内部系统数据中，不暴露到工作表单元格。同 ID 回导保留本机图片，并继续兼容 v2/v3/v4/v5 文件。
- 兼容导入旧版 JSON 备份，支持合并导入或整体替换。
- 内置 9 页基础视觉模板，无需导入外部 PPTX；封面固定，可按需选择汇总页及七张来源路标页，密集路标自动续页，不追加需求详情页或图片页。
- 导出中心在三类导出卡片下方提供独立的全宽 PPT 白名单模块，可从人员字典配置只读/可读可写权限。PPT 使用 Windows 桌面版 PowerPoint 企业 IRM 实施真实账号授权，未授权账号不可读，导出作者保留完全控制，权限固定在导出日起六个日历月到期并显示在封面。
- IRM 检测会综合 PowerPoint 作者、Office 身份注册表和 Windows 企业工号识别当前账号，并按人员字典映射最终文档所有者；环境、账号、权限写入或回读任何一步失败都会终止导出，不生成无保护降级文件。macOS 工作台可检查配置界面，但受保护 PPT 只能在 Windows 企业 IRM 环境生成。

## 本地开发

```bash
pnpm install
pnpm dev
```

检查与构建：

```bash
pnpm check
pnpm build
```

生成本地 Mac 工作台或 Windows 便携版：

```bash
pnpm package:mac
pnpm package:win
```

当前 Windows x64 便携版由 macOS 交叉构建并完成静态资源、类型检查与自动化测试；正式分发前仍建议在 Windows 10/11 实机完成启动、录入、图片、`.roadmap` 导入导出和 PPT 导出的离线验收。

## PPT 模板与数据交接

进入“导出中心”后，可从左到右选择“需求路标”“Excel 表格”或“完整需求包”。需求路标和 Excel 均按导出中心顶部选择的起止半年生成；Excel 用于多人协作编辑和回导，完整需求包用于跨电脑无损交接全部数据与原始图片。

生产 PPT 固定保留封面，并按勾选项依次输出汇总页、运动、健康、行业、全场景、health平台、AI 和医疗送检路标页；完整选择基础为 9 页。内容超过单页容量时按同一半年、同一泳道中的卡片顺序自动续页，续页重复半年、HMOS 版本和泳道表头，标注续页序号，字体不小于 8pt；保留所有卡片及各自标识，整份文件统一应用原有 IRM 权限及到期时间，导出完成后显示实际页数。单张卡片的标题及一条需求在最小字号下仍无法独立放入单元格时，明确提示对应路标、泳道、半年和领域，需缩短该标题后再导出。即使所选路标无数据也会输出完整空状态页，所有内容保持原生可编辑，不上传需求或图片。

`.roadmap` 数据包始终导出整个工作区，不受当前筛选和半年区间影响，并携带人员责任矩阵、PPT 白名单和分层分级数据。接收方选择合并前会看到所有记录及字段差异，逐项确认后才可按更新时间合并；完整备份也可选择整体替换本机业务数据。

首次建立历史基线时，在“导出中心”选择导入 `outputs/tiering-v0.8.0/历史已上市需求-分层分级-v0.8.0.roadmap`。该初始包固定只能合并，重复导入按稳定功能 ID 去重；它会增加 156 条历史需求、对应 L0/L1 领域、9 个产品系列和系列支持规格，不覆盖本机产品、成员、PPT 白名单、卡片编辑和其他需求。旧四级功能会自动迁移为 L0、L1、需求三级结构。应用半年选择器可回溯到 2014H1。

协作 Excel 仅导出所选半年区间内的已有需求用于修改或显式删除，不支持新增需求或维护字典，也不携带原始图片、人员、PPT 白名单或卡片排序。领域 L0/L1 与产品字典作为内部下拉数据随文件保存。多人完成在线编辑后，应用会先校验错误和冲突，并完整列出本机值与导入后值；用户确认全部差异后才能选择保留本机冲突或使用 Excel 版本合并回导。区间外本机数据、人员和白名单不会因未出现在表格中而被删除。

旧版数据中的单一工作量会继续计入总量，并标记为“待拆分”；编辑该需求并分配到设备、App、云侧后，待拆分数自动归零。
