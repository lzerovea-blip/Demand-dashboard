# 需求路标工作台

面向运动健康、穿戴方案团队的离线需求汇总工具。它用于结构化录入需求、按领域合并路标卡片、按半年统计工作量，并按确认后的内置模板输出路标材料。

## 直接启动（macOS）

在项目根目录双击 `启动需求路标工作台.command`，或直接打开 `release/需求路标工作台.app`。

不要在浏览器里打开 `src/renderer/index.html`：它是开发源码入口，离开 Electron 桌面环境后无法访问本地数据库和文件能力。

## Windows 版本

仓库 `release` 目录提供 64 位 Windows 版本：

- `需求路标工作台-Setup-0.2.0-x64.exe`：安装版，可选择安装目录。
- `需求路标工作台-Portable-0.2.0-x64.exe`：便携版，无需安装即可运行。

两个版本均包含离线数据库、PPT 共创模板和工作区数据包能力，运行时不依赖网络。当前构建未使用商业代码签名证书，Windows 首次运行时可能显示“未知发布者”或 SmartScreen 提示；应在可信来源下载并核对发布文件。

## 当前能力

- 单机 SQLite 数据库，运行时不访问网络。
- 六类来源：运动/健康 × 基础/进阶/高阶。
- 两类分类：体验优化、产品专属；产品专属必须选择产品。
- 单个上线年月；工作量按设备、App、云侧分别录入，支持整数或小数并自动合计。
- 每条需求可补充描述和最多 5 张本地图片，图片随离线数据备份保留。
- 需求池支持按关键词、来源、分类和完整上线年月组合筛选。
- 按“领域 + 来源 + 上线年月”自动合并卡片，分类不同仍可合并。
- 按时间汇总设备/App/云侧工作量，并用圆饼图呈现三端、运动/健康、体验优化/产品专属占比。
- 固定展示三端投入分组柱状图；可切换任一端查看投入曲线与体验优化占比柱状图。
- 运动、健康两张三级泳道路标预览；全局空月份自动压缩，仅保留清晰月份标识。
- 领域卡片点击展开全部需求、产品、工作量、需求描述和图片。
- 路标轴使用单行长条卡片，最多展示三条需求标题，完整内容在详情页查看。
- 本地领域/产品字典，以及包含需求、描述、原图和卡片编辑的 `.roadmap` 完整数据交接包。
- 兼容导入旧版 JSON 备份，支持合并导入或整体替换。
- 内置 PPT 共创模板，无需导入外部 PPTX。
- 按顶部选择的半年区间离线生成可编辑 PPTX：封面、汇总占比、三端趋势、运动/健康路标和分页需求详情。
- 路标卡片可点击跳转到对应详情页；需求描述、产品匹配、三端工作量和本地图片同步写入 PPT。

## 本地开发

```bash
pnpm install
pnpm dev
```

检查与构建：

```bash
pnpm check
pnpm build
```

生成平台安装包：

```bash
pnpm package:mac
pnpm package:win
```

当前 Windows x64 安装包由 macOS 交叉构建并完成静态资源、类型检查与自动化测试；正式分发前仍建议在 Windows 10/11 实机完成启动、录入、图片、`.roadmap` 导入导出和 PPT 导出的离线验收。

## PPT 模板与数据交接

工作台内置共创版 PPT，包含汇总分析、运动路标、健康路标和领域详情四类固定输出页。进入“PPT 输出”，先在顶部选择起止半年，再点击“生成需求路标 PPT”即可按本机数据输出；“导出 6 页共创版”用于继续讨论和确认模板视觉。

生产 PPT 页数按数据动态变化：固定生成封面、汇总结构和投入趋势；每个半年生成运动、健康两张路标；每张路标卡片按每页最多两条需求分页输出详情。所有内容在本地生成，不上传需求或图片。

`.roadmap` 数据包始终导出整个工作区，不受当前筛选和半年区间影响。接收方导入前可查看数量摘要，并选择按更新时间合并或整体替换本机业务数据。

旧版数据中的单一工作量会继续计入总量，并标记为“待拆分”；编辑该需求并分配到设备、App、云侧后，待拆分数自动归零。
