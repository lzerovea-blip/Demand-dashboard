# 解决方案需求管理

面向运动健康、穿戴方案团队的离线需求汇总工具。它用于结构化录入需求、按领域合并路标卡片、按半年统计工作量，并按确认后的内置模板输出路标材料。

## 直接启动（macOS）

在项目根目录双击 `启动解决方案需求管理.command`，或直接打开 `release/解决方案需求管理.app`。

请通过桌面应用打开工作台；应用启动时会直接加载离线需求库，启动失败时保留可复制的诊断信息。

## Windows 版本

GitHub Release 仅提供 64 位 Windows 便携版：

- `Solution-Requirements-Manager-Portable-<版本号>-x64.exe`：便携版，无需安装即可运行。

便携版包含离线数据库、PPT 共创模板和工作区数据包能力，运行时不依赖网络。后续 GitHub Release 只上传 Windows 便携版，不上传安装版、Mac 或 iOS 产物。当前构建未使用商业代码签名证书，Windows 首次运行时可能显示“未知发布者”或 SmartScreen 提示；应在可信来源下载并核对发布文件。

## 本地开发

```bash
pnpm install
pnpm dev
```

检查与构建：

```bash
pnpm check
pnpm build
```

生成本地 Mac 工作台或 Windows 便携版：

```bash
pnpm package:mac
pnpm package:win
```

当前 Windows x64 便携版由 macOS 交叉构建并完成静态资源、类型检查与自动化测试；正式分发前仍建议在 Windows 10/11 实机完成启动、录入、图片、`.roadmap` 导入导出和 PPT 导出的离线验收。

## PPT 模板与数据交接

进入“导出中心”后，可从左到右选择“需求路标”“Excel 表格”或“完整需求包”。需求路标、协作 Excel 和只读分层分级 Excel 均按导出中心顶部选择的起止半年生成；协作 Excel 用于多人编辑和回导，分层分级 Excel 用于分享、查看和核对支持矩阵及规格明细，完整需求包用于跨电脑无损交接全部数据与原始图片。

生产 PPT 固定保留封面，并按勾选项依次输出汇总页、运动、健康、行业、全场景、health平台、AI 和医疗送检路标页；完整选择基础为 9 页。内容超过单页容量时按同一半年、同一泳道中的卡片顺序自动续页，续页重复半年、HMOS 版本和泳道表头，标注续页序号，字体不小于 8pt；保留所有卡片，整份文件统一应用原有 IRM 权限及到期时间，导出完成后显示实际页数。单张卡片的标题及一条需求在最小字号下仍无法独立放入单元格时，明确提示对应路标、泳道、半年和领域，需缩短该标题后再导出。即使所选路标无数据也会输出完整空状态页，所有内容保持原生可编辑，不上传需求或图片。医疗时间轴只在应用全屏预览中展示，不进入 PPT。

`.roadmap` 数据包始终导出整个工作区，不受当前筛选和半年区间影响，并携带人员责任矩阵、PPT 白名单和分层分级数据。接收方选择合并前会看到所有记录及字段差异，逐项确认后才可按更新时间合并；完整备份也可选择整体替换本机业务数据。

首次建立历史基线时，在“导出中心”选择导入 `outputs/tiering-v0.8.0/历史已上市需求-分层分级-v0.8.0.roadmap`。该初始包固定只能合并，重复导入按稳定功能 ID 去重；它会增加 156 条历史需求、对应 L0/L1 领域、9 个历史产品系列和系列支持规格，应用会自动补齐至当前 15 个内置系列，不覆盖本机产品、成员、PPT 白名单、卡片编辑和其他需求。旧四级功能会自动迁移为 L0、L1、需求三级结构。应用半年选择器可回溯到 2014H1。

协作 Excel 仅导出所选半年区间内的已有需求用于修改或显式删除，不支持新增需求或维护字典，也不携带原始图片、人员、PPT 白名单或卡片排序。领域 L0/L1 与产品字典作为内部下拉数据随文件保存。多人完成在线编辑后，应用会先校验错误和冲突，并完整列出本机值与导入后值；用户确认全部差异后才能选择保留本机冲突或使用 Excel 版本合并回导。区间外本机数据、人员和白名单不会因未出现在表格中而被删除。

旧版数据中的单一工作量会继续计入总量，并标记为“待拆分”；编辑该需求并分配到五项工作量后，待拆分数自动归零。
