# 解决方案需求管理

面向运动健康、穿戴方案团队的离线需求汇总工具。它用于结构化录入需求、按领域合并路标卡片、按半年统计工作量，并按确认后的内置模板输出路标材料。

## 直接启动（macOS）

在项目根目录双击 `启动解决方案需求管理.command`，或直接打开 `release/解决方案需求管理-v0.7.0.app`。

不要在浏览器里打开 `src/renderer/index.html`：它是开发源码入口，离开 Electron 桌面环境后无法访问本地数据库和文件能力。

## Windows 版本

仓库 `release` 目录提供 64 位 Windows 版本：

- `解决方案需求管理-Setup-0.7.0-x64.exe`：安装版，可选择安装目录。
- `解决方案需求管理-Portable-0.7.0-x64.exe`：便携版，无需安装即可运行。

两个版本均包含离线数据库、PPT 共创模板和工作区数据包能力，运行时不依赖网络。当前构建未使用商业代码签名证书，Windows 首次运行时可能显示“未知发布者”或 SmartScreen 提示；应在可信来源下载并核对发布文件。

## 当前能力

- 单机 SQLite 数据库，运行时不访问网络。
- 侧栏显示应用版本、发版时间和制作者，并提供内置使用说明及 [GitHub 更新地址](https://github.com/lzerovea-blip/Demand-dashboard)。
- 十一类来源：运动/健康各含基础、进阶、高阶，以及行业、全场景、health平台、AI、医疗送检。
- 领域字典分为 L0 与 L1，一个 L0 可关联多个 L1；新建需求先选 L0，再从其子级中选择 L1，路标卡片只显示并按 L1 合并。
- 两类分类：体验优化、产品专属；仅产品专属显示匹配产品，并且只能选择一个产品。
- 单个上线年月；设备、App、云侧三端工作量均为必填，暂无投入可填 0，支持整数或小数并自动合计。
- 每条需求可补充描述和最多 5 张本地图片，图片随离线数据备份保留。
- 需求池支持按关键词、来源、分类和完整上线年月组合筛选。
- 按“领域 L1 + 来源 + 上线年月”自动合并卡片，分类不同、L0 不同仍可合并。
- 按时间汇总设备/App/云侧工作量，并用圆饼图呈现三端、七类路标来源、体验优化/产品专属占比。
- 固定展示三端投入分组柱状图；可切换任一端查看投入曲线与体验优化占比柱状图。
- 运动、健康、行业、全场景、health平台、AI、医疗送检七张路标；页面内“全屏查看”进入七 Tab 沉浸模式，系统窗口全屏只放大普通页面，按 Esc 退出沉浸模式。运动与健康保留三级泳道，其余路标使用单一需求泳道；全局空月份自动压缩。
- 领域卡片点击展开全部需求、产品、工作量、需求描述和图片。
- 路标轴使用单行长条卡片，最多展示三条需求标题和产品标识，完整内容在详情页查看。
- 本地领域 L0 / L1 / 产品字典，以及包含需求、描述、原图和卡片编辑的 `.roadmap` 完整数据交接包。
- 支持导出/回导 v2 标准协作 Excel，包含两级领域、单选产品、卡片编辑和必填三端工作量；同 ID 回导保留本机图片。
- 兼容导入旧版 JSON 备份，支持合并导入或整体替换。
- 内置 PPT 共创模板，无需导入外部 PPTX。
- 按顶部选择的半年区间离线生成可编辑 PPTX：封面、汇总占比、三端趋势、七张来源路标和分页需求详情。
- 路标卡片可点击跳转到对应详情页；需求描述、产品匹配、三端工作量和本地图片同步写入 PPT。

## 本地开发

```bash
pnpm install
pnpm dev
```

检查与构建：

```bash
pnpm check
pnpm build
```

生成平台安装包：

```bash
pnpm package:mac
pnpm package:win
```

当前 Windows x64 安装包由 macOS 交叉构建并完成静态资源、类型检查与自动化测试；正式分发前仍建议在 Windows 10/11 实机完成启动、录入、图片、`.roadmap` 导入导出和 PPT 导出的离线验收。

## PPT 模板与数据交接

进入“导出中心”后，可从左到右选择“需求路标”“Excel 表格”或“完整需求包”。需求路标按顶部选择的起止半年生成可编辑 PowerPoint；Excel 用于多人协作编辑和回导；完整需求包用于跨电脑无损交接全部数据与原始图片。

生产 PPT 页数按数据动态变化：固定生成封面、汇总结构和投入趋势；每个半年生成运动、健康、行业、全场景、health平台、AI、医疗送检七张路标；每张路标卡片按每页最多两条需求分页输出详情。所有内容在本地生成，不上传需求或图片。

`.roadmap` 数据包始终导出整个工作区，不受当前筛选和半年区间影响。接收方导入前可查看数量摘要，并选择按更新时间合并或整体替换本机业务数据。

协作 Excel 同样导出全部结构化数据，但不携带原始图片；多人完成在线编辑后，可在应用内预检新增、修改、删除、冲突和单元格错误，再选择保留本机或使用 Excel 版本合并回导。

旧版数据中的单一工作量会继续计入总量，并标记为“待拆分”；编辑该需求并分配到设备、App、云侧后，待拆分数自动归零。
